# 🔄 GitHub Actions Workflows для i2pd-tools

## 📋 Обзор

Создан полный набор GitHub Actions workflows для автоматизации разработки, сборки, тестирования и развертывания проекта i2pd-tools.

## 🚀 Созданные Workflows

### 1. 🔨 [build.yml](.github/workflows/build.yml) - Автоматическая сборка
**Назначение:** Сборка проекта на всех поддерживаемых платформах

**Особенности:**
- ✅ Сборка на Windows (MSYS2), Linux (Ubuntu), macOS
- ✅ Поддержка компиляторов GCC и Clang
- ✅ Автоматическая установка зависимостей
- ✅ Создание артефактов для каждой платформы
- ✅ Детальная сводка результатов сборки

**Триггеры:**
- Push в основные ветки (main, master, develop)
- Pull Request
- Ручной запуск с выбором компилятора

### 2. 🧪 [test.yml](.github/workflows/test.yml) - Тестирование
**Назначение:** Функциональное тестирование всех инструментов

**Особенности:**
- ✅ Тестирование основных функций (keygen, keyinfo, i2pbase64, x25519)
- ✅ Кроссплатформенное тестирование
- ✅ Валидация примеров из документации
- ✅ Проверка справки всех инструментов
- ✅ Автоматическая очистка тестовых файлов

**Тестируемые функции:**
- Генерация ключей I2P
- Кодирование/декодирование Base64
- Генерация X25519 ключей
- Работа с vanity адресами
- Функции семейства роутеров

### 3. 🚀 [release.yml](.github/workflows/release.yml) - Автоматические релизы
**Назначение:** Создание и публикация релизов

**Особенности:**
- ✅ Автоматическое создание релизов при push тегов
- ✅ Сборка релизных версий для всех платформ
- ✅ Создание архивов с инструментами
- ✅ Генерация release notes
- ✅ Публикация на GitHub Releases

**Артефакты релиза:**
- Архивы для Windows, Linux, macOS
- Версии с GCC и Clang
- README файлы для каждого релиза
- Автоматические release notes

### 4. 🔍 [quality.yml](.github/workflows/quality.yml) - Контроль качества
**Назначение:** Проверка качества кода и безопасности

**Особенности:**
- ✅ Линтинг C++ кода (cppcheck, clang-tidy)
- ✅ Проверка форматирования кода
- ✅ Сканирование безопасности
- ✅ Анализ размера бинарных файлов
- ✅ Проверка зависимостей

**Проверки качества:**
- Статический анализ кода
- Соответствие стандартам форматирования
- Поиск потенциальных уязвимостей
- Мониторинг размера бинарников
- Актуальность зависимостей

### 5. 📚 [docs.yml](.github/workflows/docs.yml) - Документация
**Назначение:** Проверка и генерация документации

**Особенности:**
- ✅ Проверка наличия и качества документации
- ✅ Валидация примеров из README и BUILD
- ✅ Автоматическая генерация справки по инструментам
- ✅ Создание артефактов документации

**Проверки документации:**
- Наличие README.md и BUILD.md
- Корректность примеров использования
- Генерация справки по всем инструментам
- Статистика документации

## 🚀 Как использовать

### Автоматический запуск
Workflows запускаются автоматически при:
- Push в основные ветки
- Создании Pull Request
- Push тегов (для релизов)

### Ручной запуск
1. Перейдите в раздел "Actions" в GitHub
2. Выберите нужный workflow
3. Нажмите "Run workflow"
4. Выберите параметры

### Создание релиза
```bash
# Создать тег
git tag v1.0.0

# Отправить тег
git push origin v1.0.0
```

Или используйте ручной запуск с указанием версии.

## 📊 Мониторинг и отчеты

### Статус сборки
- ✅ Зеленая галочка - все проверки прошли
- ⚠️ Желтый треугольник - есть предупреждения
- ❌ Красный крестик - ошибки

### Артефакты
Все артефакты сохраняются на 30 дней:
- Собранные бинарники
- Документация
- Отчеты о тестировании
- Релизные архивы

### GitHub Step Summary
Каждый workflow создает детальный отчет в GitHub Step Summary с:
- Результатами сборки
- Статистикой тестирования
- Анализом качества кода
- Рекомендациями по улучшению

## 🔧 Технические детали

### Зависимости
Workflows автоматически устанавливают:
- **Windows:** MSYS2, mingw64/clang64, Boost, OpenSSL, Zlib
- **Linux:** build-essential, libboost-all-dev, libssl-dev, zlib1g-dev
- **macOS:** Homebrew, Boost, OpenSSL, Zlib

### Переменные окружения
- `MAKEFLAGS: -j2` - параллельная сборка
- `GITHUB_TOKEN` - доступ к API GitHub

### Матричная сборка
Используется matrix strategy для:
- Тестирования на разных ОС
- Сборки с разными компиляторами
- Создания релизов для всех платформ

## 🐛 Устранение неполадок

### Частые проблемы
1. **Ошибки сборки на Windows** - проверьте MSYS2 и toolchain
2. **Проблемы с линковкой** - проверьте BOOST_SUFFIX и зависимости
3. **Нестабильные тесты** - некоторые тесты могут быть нестабильными

### Логи и отладка
Все логи доступны в разделе "Actions" GitHub с детальной информацией о каждом шаге.
